# Система записи на консультации (Вариант 4)

## Описание проекта
Учебный проект по УП.09.01. Веб-приложение для автоматизации записи студентов на консультации преподавателей. 
**Основное правило предметной области:** запрет записи на прошедшее время и запрет двойной записи на один временной интервал.

## Стек технологий
*   **Сервер:** OpenServer Panel (Apache)
*   **Язык программирования:** PHP 8.1
*   **База данных:** MySQL / MariaDB
*   **Фронтенд:** HTML5, CSS3

## Инструкция по запуску
1. Запустите OpenServer Panel (иконка в трее).
2. Убедитесь, что запущены модули **Apache** и **MySQL**.
3. В настройках OpenServer убедитесь, что корневой папкой проектов является папка `domains`.
4. Скопируйте папку с проектом (`consultations`) в директорию `C:\OSPanel\domains\localhost\`.
5. В адресной строке браузера введите: `http://localhost/consultations/index.php`.

## Создание базы данных и загрузка учебных данных
Для корректной работы приложения необходимо развернуть базу данных:
1. Откройте **phpMyAdmin** (в OpenServer: меню трея -> Дополнительно -> phpMyAdmin).
2. Создайте новую базу данных с именем `consultations_db` (кодировка `utf8mb4_general_ci`).
3. Выберите созданную базу, перейдите на вкладку **"Импорт"**.
4. Выберите файл **`consultations_db.sql`** (находится в корне проекта) и нажмите кнопку **"Импорт"** (или "Выполнить").
5. В результате будут созданы таблицы `users`, `slots`, `appointments` и загружены тестовые данные (более 20 записей).

## Порядок проверки операций (Тестовые аккаунты)
В базе данных предусмотрены тестовые пользователи (пароль для всех: `12345`):
*   **Студент:** логин `student1`
*   **Преподаватель:** логин `teacher1`

**Как проверить работу:**
1. Зайдите на главную страницу. Вы увидите список свободных слотов.
2. Нажмите «Записаться» на любом слоте. Введите тему обращения и подтвердите. Появится сообщение об успехе.
3. Вернитесь на главную. Слот исчезнет из списка (так как он занят).
4. Попробуйте перейти по прямой ссылке на этот же слот (например, `book.php?slot_id=1`) и записаться снова. Система выдаст ошибку «Этот интервал уже занят».
5. Для отмены записи снова зайдите в карточку слота и нажмите красную кнопку «Отменить запись».
